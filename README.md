
# Python Hangman Game 🎮

## About the Project
This is my first Python project. It is a simple Hangman Game where the computer randomly selects a fruit name and the player has to guess the word letter by letter.

## Features
- Random word selection
- Letter-by-letter guessing
- Limited attempts
- Win and Lose conditions

## Technologies Used
- Python
- Random Module
- While Loop
- For Loop
- If-Else Statements

## How to Run
1. Install Python.
2. Download the project.
3. Open the project in VS Code.
4. Run the following command:

`python hangman.py`
